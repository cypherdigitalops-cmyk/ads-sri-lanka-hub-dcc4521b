# Project rules
- Keep digital-marketing editorial content in a browser-safe, pathname-keyed data module shared by page templates and standalone pages; this ensures each public page receives one consistent guide and FAQ set.
- Preserve pathname-based contact routing during editorial changes; content improvements must not reroute customer inquiries.
- Mount the social-media promotional popup once in the root shell and exclude admin/login pages; shared mounting prevents duplicate dialogs and preserves dismissal across navigation.
